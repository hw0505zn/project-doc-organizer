# evalset/ —— 评测集

| 目录 | 内容 | 是否入库 |
|---|---|---|
| `docs/` | **原始资料副本**（真实工程资料：合同、金额、单位名称） | ❌ **不入库**（`.gitignore`，脱敏）；由 `python _pick_evalset.py` 从 `data/raw` 本地重建 |
| `gold/` | 标准答案 JSON（每份 13 字段 + `_标注来源`） | ✅ 入库 |
| `gold/_标注说明.md` | ⚠️ 当前 gold 是**演示标注**（AI 读原文生成），非人工标注 | ✅ 入库 |

## 怎么重建原始资料

```powershell
python _pick_evalset.py          # 从 data/raw 复制 30 份（10 扫描件 + 20 电子）
python _pick_evalset.py --label  # 顺便标出电子/扫描件
```

## ⚠️ 当前状态

`gold/` 里的答案是 **AI 读原文生成的演示标注**，跑出来的准确率是**演示值**（53.4%），
**不能作为真实准确率**。要真实数字：人工重标 → 删掉 `_标注来源` → 重跑 `python core\evaluate.py`。

详见 `docs/07_评测口径.md` 与 `docs/08_准确率报告.md`。
