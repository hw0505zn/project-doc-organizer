# ⚠️ 本目录的 gold 是【演示标注】，不是人工标注

- 生成方式：**AI 读 `evalset/docs/` 里的原文**填的（脚本 `_fill_gold_demo.py`）。
- **没有**抄 `results/` 里系统的输出（那是自欺红线，跑出来必是 100%）。
- 但依然违反 M3-6 §3.1 第 2 条：**每个字段都应是人工标注的**。
- 每份 JSON 里都带 `_标注来源` 字段留痕。

## 因此

| 能做什么 | 不能做什么 |
|---|---|
| ✅ 用它跑通 `evaluate.py` / `_error_taxonomy.py` / `_score_summary.py` / `_regress.py` 的**全流程** | ❌ 把跑出来的准确率写进简历、面试、交付报告 |
| ✅ 验证口径和脚本对不对 | ❌ 拿它做"改进前后"的效果对比（噪声太大） |

## 怎么变成真实评测集

1. 打开 `evalset/docs/` 里的原文，**逐格重标**（脚本：先 `python _dump_text.py --rest` 导原文）。
2. 标完一份，就删掉那份 JSON 里的 `_标注来源` 字段（表示"这份是人工标的"）。
3. 重跑 `python core\evaluate.py` → 出来的才是**真实准确率**。
4. 在 `docs/07_评测口径.md` 的「标注方式」里改成"人工标注"，并删掉顶部的演示声明。
